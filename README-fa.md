# jolly-tur-mcp 🇹🇷

سرور MCP غیررسمی و **فقط‌خواندنی** برای **جولی تور** (jollytur.com)، یکی از ۳ توراپراتور بزرگ ترکیه — جست‌وجوی هتل با قیمت زنده، جزئیات هتل و کمپین‌های جاری.

> بخشی از «کارخانه‌ی MCP ترکیه». هیچ وابستگی به جولی تور ندارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "jolly": {
      "command": "uvx",
      "args": ["jolly-tur-mcp==0.1.1"]
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `jolly_search_hotels` | جست‌وجوی هتل در یک شهر — ‏`city` (مثل «antalya»)، ‏`check_in`/`check_out` (به قالب YYYY-MM-DD؛ هر دو برای قیمت لازم‌اند)، ‏`page`، ‏`hotel_name` |
| `jolly_get_hotel` | جزئیات یک هتل — ‏`hotel_slug` (مثلاً «the-x-belek») یا آدرس کامل |
| `jolly_list_campaigns` | کمپین‌های جاری (از /kampanyalar) |

نکته‌ها:
- قیمت‌ها به لیر ترکیه (TRY) و برای اقامت درخواستی هستند؛ بدون تاریخ، قیمتی نمایش داده نمی‌شود (`prices_available: false`).
- جست‌وجوها کندند (~۱۰ تا ۱۵ ثانیه: سایت نتایج را برای هر درخواست سمت سرور می‌سازد و گاهی گیر می‌کند — سرور یک بار دوباره تلاش می‌کند). برای هر سؤال یک جست‌وجو کافی است.
- داده: جریان لیست/جست‌وجوی خود جولی — بدون کلید، بدون لاگین، فقط‌خواندنی.

## قوانین

غیررسمی و فقط‌خواندنی — بدون لاگین، بدون کلید، بدون نوشتن. تست‌ها: آفلاین با فیکسچر + تست زنده (۱۳/۱۳ سبز).
